# CampusFix-Campus-Issue-Reporting-System
CampusFix is web-based platform that allows university students to report campus issues such as broken equipment, electrical faults, plumbing problems, and damaged facilities. It provides a centralized system for submitting reports, tracking their status, and helping university authorities monitor and prioritize campus-related problems efficiently.
